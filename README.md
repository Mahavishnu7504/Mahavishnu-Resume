# Maha Vishnu A | Portfolio

A terminal-themed personal portfolio built with plain HTML, CSS, and JavaScript. No frameworks or build step.

## Features

- BIOS-style boot screen with a skip option
- Sections: Home, About, Skills, Experience, Projects, Contact
- Typing animation and glitch effect in the hero
- Interactive terminal in the contact section (`help`, `about`, `skills`, `contact`, `resume`, `clear`)
- Responsive layout with a mobile menu

## Run Locally

Open `index.html` in your browser. No setup is needed.

## Deploy

It's a static page, so it works on GitHub Pages, Netlify, or Cloudflare Pages.
